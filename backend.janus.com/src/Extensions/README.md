# Extensions Module

Manages the Janus extension registry — a catalogue of installed plugins, hooks, layouts, and other integration components. Each **Extension** entry records the package name, type, version, and active state.

---

## Domain Entity: `Extension`

| Property      | Type            | Notes                                              |
|---------------|-----------------|----------------------------------------------------|
| `id`          | `string`        | UUIDv7, generated by constructor                   |
| `name`        | `string`        | Package/bundle name — unique per type              |
| `type`        | `ExtensionType` | Integration kind                                   |
| `version`     | `string`        | Semantic version string (e.g. "1.0.0")             |
| `enabled`     | `bool`          | Defaults to `false`; must be explicitly activated  |
| `description` | `?string`       | Optional human-readable description                |
| `meta`        | `?array`        | JSON entry-point configuration, or null            |
| `createdAt`   | `\DateTimeImmutable` | Set at construction                          |
| `updatedAt`   | `\DateTimeImmutable` | Set at construction; refreshed on any mutation |

Mutating setters (`setEnabled`, `setVersion`, `setMeta`) automatically refresh `updatedAt`. A `reconstitute()` static factory reloads persisted records without generating a new ID or resetting timestamps.

## Enum: `ExtensionType`

| Case         | Value          | Description                                       |
|--------------|----------------|---------------------------------------------------|
| `INTERFACE_` | `'interface'`  | Custom Admin UI component (underscore to avoid PHP keyword) |
| `ENDPOINT`   | `'endpoint'`   | Custom API endpoint registered in the router      |
| `HOOK`       | `'hook'`       | Event hook reacting to lifecycle events           |
| `OPERATION`  | `'operation'`  | Custom Flow operation node                        |
| `DISPLAY`    | `'display'`    | Custom field-value display component              |
| `LAYOUT`     | `'layout'`     | Custom content browser layout                     |
| `MODULE`     | `'module'`     | Top-level Admin navigation module                 |
| `PANEL`      | `'panel'`      | Custom dashboard panel component                  |

Note: The PHP reserved word `interface` is handled by using `INTERFACE_` (with trailing underscore) as the case name, while the backing string value is `'interface'`.

## REST Endpoints

| Method   | Path                   | Auth          | Description                               |
|----------|------------------------|---------------|-------------------------------------------|
| `GET`    | `/extensions`          | Authenticated | Paginated list with optional filters      |
| `GET`    | `/extensions/{id}`     | Authenticated | Single extension by UUID                  |
| `POST`   | `/extensions`          | ROLE_ADMIN    | Register a new extension                  |
| `PATCH`  | `/extensions/{id}`     | ROLE_ADMIN    | Update enabled, version, or meta          |
| `DELETE` | `/extensions/{id}`     | ROLE_ADMIN    | Remove an extension from the registry     |

### Query Parameters (`GET /extensions`)

| Parameter | Type     | Default | Description                                     |
|-----------|----------|---------|-------------------------------------------------|
| `limit`   | `int`    | `25`    | Records per page (min 1)                        |
| `offset`  | `int`    | `0`     | Pagination offset                               |
| `type`    | `string` | —       | Filter by ExtensionType value string            |
| `enabled` | `bool`   | —       | Filter by enabled state (`true` / `false`)      |

### Response Envelope

```json
// Collection (GET /extensions)
{
  "data": [
    {
      "id": "uuid",
      "name": "my-hook",
      "type": "hook",
      "version": "1.2.0",
      "enabled": true,
      "description": "Runs after content is saved",
      "meta": { "entry": "dist/hook.js" },
      "createdAt": "2024-01-01T00:00:00+00:00",
      "updatedAt": "2024-06-01T00:00:00+00:00"
    }
  ],
  "meta": { "total_count": 12, "filter_count": 12 }
}

// Error
{
  "errors": [{ "message": "Extension 'uuid' not found.", "extensions": { "code": "NOT_FOUND" } }]
}
```

### `POST /extensions` — Request Body

```json
{
  "name":        "my-hook",
  "type":        "hook",
  "version":     "1.0.0",
  "enabled":     false,
  "description": "Optional description",
  "meta":        { "entry": "dist/hook.js" }
}
```

`name`, `type`, and `version` are required. `enabled` defaults to `false`.

### `PATCH /extensions/{id}` — Request Body

Only include fields you want to change. Omitted fields are left unchanged.

```json
{
  "enabled": true,
  "version": "2.0.0",
  "meta": { "entry": "dist/v2/hook.js" }
}
```

## `UpdateExtensionCommand` — UNCHANGED Sentinel

The command carries a sentinel value `'__UNCHANGED__'` for fields that should not be mutated. The handler skips any field whose value equals the sentinel:

```php
if ($command->enabled !== UpdateExtensionCommand::UNCHANGED) {
    $extension->setEnabled((bool) $command->enabled);
}
```

## Access Control

- `GET /extensions` and `GET /extensions/{id}` — accessible to all authenticated clients (`WEB`, `IOS`, `ANDROID`, `CLI`)
- `POST`, `PATCH`, `DELETE` — require `ROLE_ADMIN` (clients: `WEB`, `CLI` only)
