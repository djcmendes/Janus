# Versions Module

Manages the Janus content-versioning system. Each **Version** captures a named snapshot of an item's data within a collection, enabling non-destructive history and the ability to restore (`promote`) a snapshot back into the live row.

## Domain Entity: `Version`

| Property     | Type                  | Notes                                                      |
|--------------|-----------------------|------------------------------------------------------------|
| `id`         | `string`              | UUIDv7, generated by constructor                           |
| `collection` | `string`              | Target collection name                                     |
| `item`       | `string`              | UUID of the item being versioned                           |
| `key`        | `string`              | Named snapshot label (e.g. `"main"`, `"draft"`)            |
| `data`       | `array`               | Full data snapshot of the item at the time of versioning   |
| `delta`      | `?array`              | Optional change delta between this and the previous state  |
| `userId`     | `?string`             | UUID of the user who created the version, or null          |
| `createdAt`  | `\DateTimeImmutable`  | Set at construction                                        |
| `updatedAt`  | `?\DateTimeImmutable` | Null on creation; refreshed on key/delta mutation          |

A `reconstitute()` static factory reloads persisted records without generating a new ID or resetting timestamps. `toArray()` returns a serialisable representation of all fields.

---

## Domain Service: `VersionService`

`promote(Version $version)` writes `$version->getData()` back into the live user-defined collection table row identified by `$version->getItem()`. It:

- Strips `id` from the SET clause to avoid overwriting the primary key.
- Guards table and column names against invalid identifiers.
- Uses parameterised queries (`executeStatement`) to prevent SQL injection.
- Throws `\RuntimeException` when `affected rows === 0` (item not found in the live table).

## REST Endpoints

| Method   | Path                       | Auth       | Description                                   |
|----------|----------------------------|------------|-----------------------------------------------|
| `GET`    | `/versions`                | ROLE_ADMIN | Paginated list with optional filters           |
| `GET`    | `/versions/{id}`           | ROLE_ADMIN | Single version by UUID                         |
| `POST`   | `/versions`                | ROLE_ADMIN | Create a new version snapshot                  |
| `PATCH`  | `/versions/{id}`           | ROLE_ADMIN | Update key or delta on an existing version     |
| `DELETE` | `/versions/{id}`           | ROLE_ADMIN | Remove a version snapshot                      |
| `POST`   | `/versions/{id}/promote`   | ROLE_ADMIN | Restore snapshot data into the live collection |

### Query Parameters (`GET /versions`)

| Parameter    | Type     | Default | Description                                         |
|--------------|----------|---------|-----------------------------------------------------|
| `limit`      | `int`    | `25`    | Records per page (min 1)                            |
| `offset`     | `int`    | `0`     | Pagination offset                                   |
| `collection` | `string` | —       | Filter by collection name                           |
| `item`       | `string` | —       | Filter by item UUID                                 |

### Response Envelope

```json
// Collection (GET /versions)
{
  "data": [
    {
      "id": "uuid",
      "collection": "articles",
      "item": "item-uuid-1",
      "key": "main",
      "data": { "title": "Hello" },
      "delta": null,
      "userId": "user-uuid",
      "createdAt": "2024-01-01T00:00:00+00:00",
      "updatedAt": null
    }
  ],
  "meta": { "total_count": 5, "filter_count": 5 }
}

// Single item (GET /versions/{id} or POST /versions)
{ "data": { ... } }

// Error
{
  "errors": [{ "message": "Version 'uuid' not found.", "extensions": { "code": "NOT_FOUND" } }]
}
```

### `POST /versions` — Request Body

```json
{
  "collection": "articles",
  "item":       "item-uuid-1",
  "key":        "main",
  "data":       { "title": "Hello" },
  "delta":      null
}
```

`collection`, `item`, `key`, and `data` are required. `(collection, item, key)` must be unique — a `409 CONFLICT` is returned otherwise.

### `PATCH /versions/{id}` — Request Body

Only include fields you want to change. Omitted fields are left unchanged.

```json
{
  "key":   "draft",
  "delta": { "title": { "old": "Hi", "new": "Hello" } }
}
```

## `UpdateVersionCommand` — UNCHANGED Sentinel

The command carries a sentinel value `'__UNCHANGED__'` for fields that should not be mutated. The handler skips any field whose value equals the sentinel:

```php
if ($command->key !== UpdateVersionCommand::UNCHANGED) {
    $version->setKey((string) $command->key);
}
```
